## Connect it

- **Claude, Cursor, Codex, Gemini and other AI apps:** setup steps at
  [datadingo.com/developers](https://datadingo.com/developers)
- **Claude Code:** install the [DataDingo plugin](https://github.com/datadingo-com/claude-plugin)

  ```
  claude plugin marketplace add datadingo-com/claude-plugin
  claude plugin install datadingo
  ```
