# Security

If you think you've found a security problem in DataDingo, please tell us privately rather than
opening a public issue.

- **Email:** [hello@datadingo.com](mailto:hello@datadingo.com) with "Security" in the subject.
- **On GitHub:** use **Report a vulnerability** on the repository's Security tab.

Please include what you found, how to reproduce it and what it could affect. We'll reply within
a few working days and keep you updated until it's fixed. Please give us a reasonable chance to fix
the problem before you tell anyone else.
